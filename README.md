# 单词保卫战 · 小学英语

面向课堂的英语单词对战小游戏。支持 **人教 PEP**（8 册 46 单元）、**冀教版**（8 册 44 单元）与 **北师大版**（8 册 38 单元）三套小学英语三至六年级教材，共 24 册 128 个单元。

[在线体验「单词保卫战」](https://niannianweike.top/tools/word-defense/)

## 本地运行

用浏览器打开根目录的 `index.html`，先选择教材版本，再按年级课本选择单元。也可以在项目目录启动静态服务器，再打开 `http://localhost:8000`。

```sh
python -m http.server 8000
```

无需安装依赖或构建。所有版本共享同一套游戏引擎、插图和离线配音，进度按教材版本独立保存。

## 文件结构

| 文件 | 用途 |
|---|---|
| `index.html` / `desk.css` / `desk.js` | 总入口（教材版本选择 + 课本选单 + 玩法讲解） |
| `play.html` / `editions.js` | 多版本通用游戏页与教材版本清单 |
| `game.css` / `game.js` | 所有单元页与整册版共用的游戏样式与核心引擎 |
| `phone-orientation.css` / `phone-orientation.js` | 手机竖屏自动暂停与横屏提示 |
| `words.js` / `words-jj.js` / `words-bnup.js` | 人教 PEP / 冀教版 / 北师大版三至六年级词表 |
| `word-icons.js` | 共享单词 SVG 插图（977 个） |
| `audio/` | 共享离线单词配音及 `audio/manifest.js` |

改样式或游戏逻辑直接改 `game.css` / `game.js`，全部单元同步生效；改单词或插图改对应 `words*.js` / `word-icons.js`。
